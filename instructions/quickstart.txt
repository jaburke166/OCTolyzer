QuickStart instructions for OCTolyzer

Option A: Double-click GUI (Recommended, no terminal required)
--------------------------------------------------------------
1. Download or clone this repository (https://github.com/jaburke166/OCTolyzer).
2. Double-click the launcher for your operating system (in `gui/launchers/` on first run, which automatically places only your OS's launcher in the root folder):
   - Windows: OCTolyzer.bat
   - macOS: OCTolyzer.command
   - Linux: OCTolyzer.sh
   (On first launch, the script automatically installs uv, creates a local Python environment with the latest Python version, and installs requirements.txt. On every launch, it checks for updates and starts `python -m gui.app`.)

Option B: Manual Python / Conda setup
-------------------------------------
1. Install Miniconda (https://docs.anaconda.com/miniconda/miniconda-install/) or Python.
2. Clone this repository via `git clone https://github.com/jaburke166/OCTolyzer.git`.
3. Install dependencies:
   pip install -r requirements.txt
4. Launch the GUI from the repository root:
   python -m gui.app
   (Or run headless batch processing via `python octolyzer/main.py` after editing `config.txt`.)
